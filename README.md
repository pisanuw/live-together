# WCV — West Complex Village

A private community web app for the residents of an apartment complex: forum,
info desk, events with sign-ups, personal event tracking, maintenance requests,
and per-user settings.

> **Status:** Stage 0 (project scaffold). See the full roadmap in
> [docs/PLAN.md](docs/PLAN.md).

## Stack

- **Next.js 16** (App Router, TypeScript) + **React 19**
- **Tailwind CSS v4** + **shadcn/ui** (Radix)
- **Supabase** — Postgres, Auth, Storage, Edge Functions, Realtime
- **Netlify** — hosting (official Next.js runtime)
- **Vitest** + Testing Library (unit) / **Playwright** (E2E)

## Prerequisites

- Node.js 22+ (this repo is developed on Node 24)
- [Supabase CLI](https://supabase.com/docs/guides/local-development) (installed)
- A Supabase project (created in Stage 1)

## Getting started

```bash
npm install
cp .env.example .env   # then fill in the values
npm run dev            # http://localhost:3000
```

The home page shows an environment-readiness panel. Until `.env` has valid
Supabase credentials, the "Supabase configuration" check stays amber.

## Environment variables

Copy `.env.example` to `.env` and fill it in. `.env` is gitignored; never commit
secrets. Only `NEXT_PUBLIC_*` variables reach the browser. Google OAuth
client credentials are configured in the Supabase dashboard, not here.

## Scripts

| Script | Description |
|---|---|
| `npm run dev` | Start the dev server (Turbopack). |
| `npm run build` | Production build. |
| `npm run start` | Serve the production build. |
| `npm run lint` | ESLint. |
| `npm run typecheck` | `tsc --noEmit`. |
| `npm run format` | Prettier (write). |
| `npm run format:check` | Prettier (check only). |
| `npm run test` | Unit/component tests (Vitest, single run). |
| `npm run test:watch` | Vitest in watch mode. |
| `npm run test:e2e` | Playwright E2E (builds + starts the app). |

Playwright needs browsers once: `npx playwright install chromium`.

```
  lib/

docs/PLAN.md           multi-stage implementation plan
e2e/                   Playwright tests
__tests__/             Vitest unit/component tests
```

## Deployment

- **Netlify:** connect the repo; the Next.js runtime is auto-installed (see
  `netlify.toml`). Set env vars in the Netlify UI.
- **Supabase:** schema is managed as SQL migrations under `supabase/migrations/`
  and applied with the Supabase CLI. Never hand-edit the remote schema.
